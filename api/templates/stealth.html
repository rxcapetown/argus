EVALS

A task is not done because the agent says so.

An agent that sounds confident and books the wrong flight has not done the task. Our evals grade the work itself, in four ways.

End state

We compare the final state of the environment with the state the task required. The right order, the right booking, the right refund. Anything else is a failure, however fluent the agent sounded.

Policy

Real work runs on rules: fare conditions, return windows, substitution limits, refund policy. An eval checks that the agent followed the rules of the domain, not only that it reached an answer.

Repetition

One success is an anecdote. We run the same task many times and report how often the agent succeeds, so a lucky run cannot pass as reliability.

Failure record

Every failed run is classified: wrong item, wrong price, a rule missed, a step skipped, gave up early. The failure record is what training teams actually fix from.

DATA WITH HUMAN JUDGEMENT

Some answers cannot be checked by a script.

Was the substitution reasonable? Was the refund fair? Did the agent follow what the customer actually meant? Our experts review, grade and correct agent work in the fields they know first-hand.

Each judgement is made against a written rubric, and a second expert checks the grade before it becomes data.

LITERATURE

The work we build on.

Argus is not affiliated with these projects. They are published work, and our environment and evaluation design follows where they lead.

YAO, SHINN, RAZAVI, NARASIMHAN · 2024

τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains

Agents serve simulated customers in retail and airline domains. Success is scored on the database state the agent leaves behind, and on consistency across repeated trials. Even strong agents proved unreliable.

ZHOU ET AL. · ICLR 2024

WebArena: A Realistic Web Environment for Building Autonomous Agents

Fully working replicas of real websites, including an e-commerce store, graded on functional correctness rather than plausible answers. The best agent in the paper finished far behind human performance.

XIE ET AL. · NEURIPS 2024

OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments

Open-ended tasks inside real computer environments, checked by execution. At release, humans completed 72% of tasks. The best model completed 12%.

ZHENG ET AL. · NEURIPS 2023

Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena

The study of automated judges: where they agree with people, and where they bend, toward the first answer, the longer answer, their own output. It is the reason human judgement stays in our grading loop.
